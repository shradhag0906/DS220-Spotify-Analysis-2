Spotify Songs Data Analysis

This project explores Spotify song data using Python and Pandas to understand what factors influence song popularity. By analyzing audio features such as danceability, energy, valence, and artist performance, we can identify trends in listener preferences.

Home Analysis

Project Overview

Music streaming platforms like Spotify generate large amounts of data that can help us understand how songs become popular. This project uses a public Spotify dataset to explore relationships between popularity and musical characteristics.

Main Goal:
Use Python, Pandas, and data visualization to discover what makes songs more popular on Spotify.

Research Questions

  • Does danceability affect song popularity?
  • Are high-energy songs more successful?
  • Do happier songs (high valence) perform better?
  • Which artists have the highest average popularity?
  • What trends exist between tempo and popularity?
  • Do explicit songs perform better than non-explicit songs?

Tools Used

  • Python
  • Pandas
  • Matplotlib
  • Jupyter Notebook
  • GitHub Pages
